# M4-A2 Capability Authorization Review

M4-A2 reviews canonical contracts only. It cannot approve or activate a
capability.

Verify one exact capability, feature branch and commit, M3 and M4-A1 bindings,
distinct requester/operator/approver identities, a non-root Mac operator, a
one-hour-or-shorter timezone-aware window, maximum uses of one, production and
Ubuntu denial, and every exact restriction acknowledgement.

Monitoring health evidence is read-only. Alert dispatch references a separately
authorized monitoring capability. External notification references a
separately authorized alert-dispatch capability. A reference never grants
either capability.

Reject environment variables, API routes, n8n, WordPress, WooCommerce, Ubuntu,
or external components as authority. Do not issue a permit, create a claim,
execute a command, start a writer or monitoring process, dispatch a
notification, or activate production. Endpoint details and secrets are
excluded; `.env` is not required.
